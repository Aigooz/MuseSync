# MuseSync 2.4.0 · 谱伴同步

Windows 10/11 x64 / MuseSync Bridge 1.4.0 / 2026-11-08

## 这次更新

- **增加谱面同步视频辅助。** 从插件“打开”菜单加载 MP4、WebM、M4V 本地视频，或在可调整大小的独立窗口打开 http/https 视频网页。视频跟随 MuseScore 谱面时间轴同步播放、暂停和跳转，谱面速度变化也会校正视频位置。
- **支持 Bilibili 页面尝试播放。** 能否播放由网站策略、地区、版权、登录状态和网页播放器决定。WebView2 使用独立的数据目录，可能需要在视频窗口中单独登录；功能不下载网络视频。
- 网页控制要求页面提供可访问的 HTML5 视频播放器；iframe、登录或网站策略可能阻止同步。
- **关闭播放器更可靠。** 修复插件关闭时视频窗口启动阶段可能无法及时退出的问题。

## 环境要求与限制

视频窗口依赖 Microsoft Edge WebView2 Runtime。Windows 11 通常已预装；若无法启动，请安装微软官方 Evergreen WebView2 Runtime。网页视频可用的编码格式也取决于系统和站点播放器。

原有安装方式、插件内更新、覆盖安装及卸载流程保持不变。2.3.0 用户可在插件右上角“？”中选择“检查更新”，检测到本版后在插件内下载并校验安装包；保存谱面并退出 MuseScore 后，运行安装器覆盖升级。

MuseScore 3 不支持 VST3。MuseScore 4 的兼容性声明和已知同步限制未作扩大；本次自动化验证不能替代不同 MuseScore 版本的实机测试。安装器尚未签名，请核对发布页 SHA-256。
