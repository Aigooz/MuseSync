# MuseSync 2.3.0 · 谱伴同步

Windows 10/11 x64 / MuseSync Bridge 1.4.0 / 2026-11-02

## 这次更新

- **在插件里更新。** 打开面板后会后台检查 GitHub 正式版，有新版时“？”会出现提示点。指南底部提供检查、下载、取消和安装入口；下载显示进度，安装前核对 SHA-256，无需跳转浏览器。更新检查不需要 GitHub 登录，不上传谱面和伴奏。
- **中文安装与覆盖升级。** 安装向导和说明改为中文，沿用上次的安装位置。下载新 EXE 后直接安装，不用先卸载；谱面、伴奏和同步 INI 保留，插件参数请先随谱面保存。
- **一键卸载。** 安装目录里新增“一键卸载 MuseSync”入口，同时移除 Bridge、VST3 和通过身份验证的旧版停用文件，不删除其他插件和用户文件。手动部署 ZIP 也附带卸载脚本。
- **VST3 文件名改正。** 文件夹和内部模块统一为 `MuseSync.vst3`。保留原来的类 ID 和参数状态，安装时将旧 `MuseTone.vst3` 归档停用，避免重复扫描。
- **界面调整。** 更新浅色与深色主题、数字字体、波形播放头标记、悬浮条小节拍数排版和内置指南，关于区保留 `@爱鸽咕子` 署名。
- **补充旧版 MuseScore 4 接口兼容。** Bridge 1.4.0 增加 Qt 5 设置组件、数值型播放时间和多声部速度扫描路径；4.6–4.7 继续使用新版分段接口。

## 下载哪个文件

- `MuseSync-Setup-2.3.0-Windows-x64.exe`：普通用户下载这一个即可，内含 VST3、Bridge、中文说明和卸载程序。EXE 是插件安装器，不是独立播放器，仍需安装 MuseScore 4。
- `MuseSync-2.3.0-Windows-x64.zip`：手动部署包，附卸载脚本与许可证。
- `MuseSync-2.3.0-Source.zip`：完整对应源码，包含固定提交的 VST3 SDK 与子模块。
- `SHA256SUMS.txt`：上述三个文件的 SHA-256 校验值。

## 从旧版升级

1. 保存谱面，退出 MuseScore 及其他使用插件的宿主。
2. 运行新版 EXE，按中文向导安装到原位置。MuseScore 改过位置时，重新选择包含 `bin\MuseScore4.exe` 的文件夹。
3. 重启 MuseScore，启用并运行 MuseSync Bridge，在混音器选择 MuseSync。旧名称仍出现在列表里时，重新扫描 VST3。

2.2.0 及更早版本没有内置更新入口，升级到本版需要先手动下载 EXE。从本版起才可以在插件里检查和下载后续更新。点击“安装更新”只会打开安装器，不会自动关闭 MuseScore，请先保存工作并退出宿主。

Bridge 的 `plugins\MuseToneSync` 路径和程序说明目录 `C:\Program Files\MuseTone` 为升级兼容保留，不需要手动改名。卸载入口位于该程序说明目录；正常升级无需先卸载。

## 验证与使用边界

发布检查覆盖 Release 编译、六组回归测试、47 项 Steinberg VST3 校验、新旧接口的无界面 QML 桥接、PowerShell 5.1/7 卸载兼容、隔离安装与覆盖升级，以及发布包版本、源码和校验值检查。

这些检查不代替 MuseScore 实机验收。4.7 是主要目标，4.0–4.6 尚未逐版本实机验证；MuseScore 3 不支持 VST3，无法使用。音符间速度标记、渐变速度、反复展开、临时播放速度倍率和多个 MuseScore 进程共享快照仍有限制。插件不会根据谱面变速自动拉伸伴奏。
