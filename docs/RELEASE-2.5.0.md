# MuseSync 2.5.0 · 谱伴同步

- 优化视频同步：缓存网页播放器与同步脚本，合并未完成的同步请求，补偿线程调度耗时，平滑速度采样；小幅漂移通过有限调速追齐，大幅失步才跳转，并避免缓冲期间连续跳转造成卡顿。
- 视频小窗新增音量滑块和延迟输入、加减按钮，位于时间与进度条下方；与大窗共享设置，缩小窗口时自动换行排布。
- 修复延迟、BPM、半音和音分输入框回车时的系统提示音，禁止键入空格或粘贴含空白的数值；无效输入不覆盖已有设置。
- 延迟滚轮每格 10 ms，按住 Ctrl 每格 100 ms，保留 Shift 每格 1 ms 精调。
- 新实例默认深色主题；旧工程明确保存的主题保持不变。

视频功能需要 Microsoft Edge WebView2 Runtime。此更新减少插件自身造成的卡顿，无法保证网络带宽不足、站点缓冲、解码能力不足时始终流畅；网站登录、版权、跨域或播放器限制仍可能影响在线视频同步。

安装前保存谱面并退出 MuseScore，再运行 2.5.0 安装程序覆盖旧版。安装包尚未签名，可通过 SHA256SUMS.txt 校验完整性。
