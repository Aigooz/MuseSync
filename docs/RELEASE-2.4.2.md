# MuseSync 2.4.2 · 谱伴同步

本次更新改进了视频窗口：本地视频和可访问的网页视频播放器会尝试跟随谱面播放、暂停、跳转和速度变化；在线视频地址输入窗口也更易操作。更新下载放宽了对慢速连接的限制，并恢复了原有控件编号。

新增素材分段 BPM：音频和本地视频音轨在后台分析，主面板显示当前位置的 BPM 估计值及可点击跳转的变化曲线。采用 MiniBPM 的 8 秒重叠窗口，每 1 秒计算一段；在线视频在播放时读取连续音频，约 6–8 秒后开始显示，跳转后重新积累。静音、持续单音或过短片段可能无法识别，复杂节奏可能出现半速或倍速估计。该功能用于观察素材速度，不会自动修改谱面速度或完成节拍对齐。

视频功能需要 Microsoft Edge WebView2 Runtime。网页的登录、版权、播放器和跨域限制可能影响播放或同步，Bilibili 等网站的实际兼容性尚未全面验证。

在插件右上角的“？”中检查更新并下载；安装前保存谱面并退出 MuseScore，再运行安装程序覆盖旧版。安装包尚未签名，可使用发布页的 SHA-256 校验文件验证。
